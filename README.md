# Campus-Connect: Centralized College Club Notification Platform
> **Design & Technology (D&T) Lab Project**

A centralized, multi-tenant notification distribution platform connecting college clubs with students through structured public and member-specific announcements.

---

## 📑 Project Documents

- 📘 [**Problem Statement (`PROBLEM_STATEMENT.md`)**](./PROBLEM_STATEMENT.md): Detailed 100+ word statement covering Target Audience, Pain Points, Solution in Mind, and Nature of Output.
- 📙 [**Ubiquitous Language (`UBIQUITOUS_LANGUAGE.md`)**](./UBIQUITOUS_LANGUAGE.md): Domain-Driven Design (DDD) domain language specification, entities, invariants, roles, and anti-patterns.

## 🎯 Quick Summary

| Dimension | Specification |
| :--- | :--- |
| **Project Name** | **Campus-Connect** |
| **Repository** | [github.com/nirav3690/Campus-Connect](https://github.com/nirav3690/Campus-Connect) |
| **Domain** | Campus Communications & Multi-Tenant Notification Distribution |
| **Target Audience** | College Students, Club Conveners & Deputy Conveners, Club Members |
| **Core Architecture** | Multi-tenant single dashboard template, dynamic tenant hydration |
| **Notification Types** | **Public** (Campus-wide) & **Members-Only** (Admin-controlled roster) |
| **Content Philosophy** | Broadcast notification aggregator with link-outs to existing websites/socials (not a CMS rebuild) |
| **Roster Control** | Admin-governed enrollment via official college email addresses |
